Read [the project orchestration protocol](../../../docs/ORCHESTRATION.md)
once for the current task. It owns routing, work orders, concurrency and
acceptance. Repository AGENTS.md and WORKFLOW.md remain authoritative for
product requirements, permissions, verification and documentation.

For substantial work, delegate a concrete independent subtask when its result
will reduce uncertainty or parallel work. Keep useful independent work for the
parent; do not spawn a worker only to wait on it. Skip unnecessary roles. Use
project custom agents when exposed by the active tool; otherwise pass the
chosen role instructions, explicit model/effort and a self-contained work order
through the available delegation tool. Check its actual schema first.

Do not claim TOML discovery, model routing, sandbox enforcement or savings from
static validation. Report unavailable capabilities and follow the protocol's
fallback without inventing tool parameters or changing permissions.
