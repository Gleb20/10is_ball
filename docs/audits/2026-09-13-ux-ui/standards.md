# Внешние критерии, проверены 2026-09-14

Это критерии отдельных проверок, не заявление о полной WCAG-сертификации Tab-10.

- [W3C: Contrast Minimum, SC1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): для обычного текста минимальное отношение 4.5:1; для большого текста 3:1, с указанными исключениями. `.judge-error`14px не относится к large text. Использовать реальные computed foreground/background с учётом композиции, не усреднённые пиксели сглаженных букв. 2.58:1 относится только к измеренной паре.
- [W3C: Focus Not Obscured Minimum, SC2.4.11](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html): собственный контент не должен полностью скрывать компонент с клавиатурным фокусом. Требование проекта полностью видеть поле и активную option над BottomNav строже этого минимального критерия; частичное пересечение само по себе не объявлять нарушением SC2.4.11. Геометрия ниже viewport не равна пересечению fixed nav.
- [W3C APG: Combobox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/): ориентир для keyboard/popup/active descendant поведения. APG — практический паттерн, не замена проверке конкретного ARIA/DOM и реальной assistive technology. DOM focus и выбранное значение/визуальная активность опции различаются; нет spoken-AT доказательства без такой проверки.

Приоритет компоновки Home/формы — экспертные предложения из принятого контекста пользователя и наблюдения приложения, а не вывод из стандарта доступности.
