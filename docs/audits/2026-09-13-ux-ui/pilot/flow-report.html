Предлагаемое поведение

  1. 1Начало/продолжение

    Основное действие выше персональных метрик; функции Home остаются.

  2. 2Состав

    Две стороны → видимая сводка правил; дополнительные опции раскрываются с текущим состоянием.

  3. 3Начать и вести

    Один основной допустимый следующий шаг; чужое судейство не перехватывается.

  4. 4Счёт

    +1, подача, отмена; передача телефона отличается от передачи устройства.

  5. 5Результат и новая игра

    Итог → Новая игра; реванш и действия с результатом доступны отдельно.

Ветви и восстановление

Инвайты добровольны. Первый подающий выбирается по правилам. Ошибочное очко отменяется; техническая коррекция — отдельное событие. Передача резервирует получателя; при истечении предложение перестаёт быть актуальным. Результат остаётся предварительным до подтверждения.
