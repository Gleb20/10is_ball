Резюме

Экспертный прогон production build прошёл первый вход и повторную авторизацию того же и другого пользователя на одноразовых локальных данных. Целевое состояние сохраняет серверную авторитетность, D34, D5 и запрет постоянного черновика MATCH-015. Два фактических дефекта относятся к FirstPassword и ошибкам авторизации; выводы о Home, действиях онбординга и textarea Help остаются экспертными гипотезами.

Уровень доказательства: автоматизация Chromium, снимки экрана, анализ исходников и требований. Нет реального пользователя, речевых вспомогательных технологий, WebKit, масштаба 200% и изменений production.

Текущий поток: первый вход

Вход: защищённая глубокая ссылка или /login · AUTH-A01

  1. 1Вход

    Email, пароль, показ пароля и подсказка об администраторе. Неверные данные сохраняют Email, но activeElement становится body.

    Основное действие: Войти → FirstPassword либо безопасная точка возврата/Home.

    Неизвестный пользователь → общая ошибка; заблокированный → предусмотренное сообщение; повторные ошибки → 429.
  2. 2Обязательная смена пароля

    Несовпадение не связано с полями; ошибка политики показывает коды. Выход открывает вход, но сохраняет сессию.

    Основное действие: Сохранить → незавершённый онбординг.

    Выйти → /login; logout POST=0 и /auth/me=200 — FAIL.
  3. 3Онбординг, шаги 1–6

    Сфокусированный заголовок и сохранённый прогресс. «Далее» и «Пропустить шаг» вызывают один переход; закрытие завершает онбординг.

    Основное действие: Далее → следующий сохранённый шаг.

  4. 4Необязательный учебный матч

    Учебный матч открывает изолированный маршрут судейства. Отмена возвращает на шаг 7 без завершения.

    Основное действие: Матч с Призрачным Олегом.

    Явное завершение остаётся обязательным по D34.
  5. 5Home нового пользователя

    Личные метрики занимают первые 300–386 px до действия «Начать»; остальные разделы HOME сохранены.

    Основное действие: Начать → /start.

Целевой поток: первый вход

  1. 1Устойчивая точка ошибки

    Те же поля и общий текст ошибки входа. Alert однократно получает фокус; неверные поля связаны с ошибкой.

    Основное действие: Войти → прежний контракт точки возврата.

  2. 2Честный выход

    Причины политики понятны; несовпадение связано с обоими полями. Выход отправляет один logout и очищает авторизацию.

    Основное действие: Сохранить → онбординг.

    Ошибка logout сохраняет поля и даёт повтор; успех → неаутентифицированный /login.
  3. 3Однозначный проводник

    Шаги 1–6 явно необязательны и дают одно «Далее» плюс полное закрытие; шаг 7 сохраняет учебный матч и явное завершение.

    Основное действие: Далее.

  4. 4Home с приоритетом задачи

    Разрешённое текущее событие или «Начать» расположено до компактной статистики. Все функции HOME сохраняются.

    Основное действие: Продолжить при разрешённом действии; иначе Начать игру.

Восстановление сессии во время работы

Смонтированная защищённая форма получает 401 · AUTH-A02

  1. 1Отклонённая мутация

    Глобальная авторизация скрывает защищённое дерево без размонтирования и фокусирует Email на том же безопасном path/query/hash.

    Основное действие: Войти.

  2. 2AТот же пользователь

    Возврат с прежними названием и гостем. Create POST остаётся один; повтора нет.

  3. 2BДругой пользователь

    Защищённое дерево перемонтируется; прежние поля и выборы исчезают.

MATCH-015 удаляет черновик при обычном выходе с маршрута или размонтировании. Исключение — только временное смонтированное состояние, не localStorage и не серверное хранение.
