# GAP-012 filled suggestion matrix

This directory preserves the bounded diagnostic requested after the single R2 browser timeout. It is not a full browser acceptance run and does not replace the earlier full-suite evidence.

The run used one disposable PostgreSQL 16.15 stand, compiled API/web artifacts, desktop Chromium, and one execution of each named phase. A route-only synthetic create-options response retained the real disposable users and rendered 3 frequent, 3 recent, and 1 team button above the player field. The resulting suggestion region was 476 px high. It is UI timing evidence, not database roster evidence.

All four flows passed. The response-on-input and after-fill phases observed the options and the 476 px region commit after the input event, a transient `outsideMargin12=true` at scroll Y 224, scroll recovery to Y 654, then pointer/mouse down, option removal and `aria-expanded` true-to-false. The query and input node identity were retained. This controlled run did not reproduce selection loss and does not establish that the rare race is absent.

`vendorDOMShapeMatches` is false because the frozen helper incorrectly required `data-readonly` on an editable control. ic-kit emits that attribute only for a read-only field. The raw rectangles, measured safe-bottom value, scroll positions and event order remain available, but the boolean shape gate itself is invalid. No rerun or product change followed this finding.
