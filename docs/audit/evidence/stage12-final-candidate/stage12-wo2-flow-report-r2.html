Stage 12 BUG-038 WO2: безопасный сброс пароля

Отчёт фиксирует реализованный клиентский путь поверх принятого серверного WO1 R2.

Основной путь

  1. Администратор открывает действия пользователя на каталоге или карточке аккаунта.
  2. Клиент получает свежий указатель состояния и показывает отдельное подтверждение.
  3. До POST сохраняется только корреляция: actor, target, request и ожидаемый указатель.
  4. Первый точный ответ может показать временный пароль только в памяти.
  5. Копирование не закрывает пароль; закрытие, смена актора или явный выход уничтожают показ.

Восстановление и ошибки

СостояниеДействие клиента
Неизвестный результат POSTТолько receipt GET; исходный POST не повторяется.
Receipt applied без секретаСообщает, что секрет восстановить нельзя; при current=false предупреждает о более позднем сбросе.
Новая выдачаСвежий state GET, отдельное подтверждение, новый UUID и supersedesRequestId.

IDEMPOTENCY_KEY_REUSEDТерминальная ошибка; требуется новое ручное действие.
401 / 403 / снятие ролиАннулирует операцию и поздний ответ; собственный первый ответ self reset переживает только автоматический 401.
Недоступен sessionStorageОперация продолжается в памяти с предупреждением об отсутствии восстановления после reload.

Rollout

Исходный флаг остаётся false.

Кнопка показывает удерживающий текст. Отдельный однострочный patch включает путь только после миграции и drain старого серверного fleet.
