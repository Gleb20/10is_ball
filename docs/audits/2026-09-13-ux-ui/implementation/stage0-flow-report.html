Поток 1 · Home → матч → судейство → следующий шаг

1. HomeТекущая задача по роли; прямой «Начать матч» → `/matches/new`. История и вторичные разделы обнаружимы.
2. Состав и правилаОператор выбирает A и B вне собственного игрового места. Редкие правила доступны, приглашения в игру скрыты.
3. МатчПроверка состава, судьи и start rights. Сокращение create/acquire/start зависит от Q-UX-006.
4. СудействоОдин active judge; score intent/version/idempotency, восстановление по authoritative GET, доступный выход.
5. РезультатImmutable result и auditable void по D24/D33; следующий шаг виден по роли. Replay/10-second Undo требуют решений.

Общая семантика статусных чипов и иконок проходит inventory/target GAP-034 в этапе 3; match/judge применяет её в этапе 6. Статус не выглядит действием без действия, serve icon остаётся отдельным judge consumer.

Поток 2 · Home → турнир → сетка → матч → та же сетка

1. HomeПрямой «Провести турнир»; организатор может не играть.
2. Правила и составПонятная сетка проигравших; `requireParticipantConsent=false`; direct roster в прежних правах.
3. Draft bracketСетка на первом плане, read-only summary, управление посевом и перестройкой до старта.
4. Active bracketРабочий этап и разрешённые готовые пары; переход в матч и возврат к той же сетке.
5. OutcomeПосле результата краткий top-3 с доступом к полным итогам; stopped — без чемпиона.
